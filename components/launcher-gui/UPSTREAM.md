# Происхождение GUI

Начальная версия основана на GravitLauncher/LauncherRuntime:
https://github.com/GravitLauncher/LauncherRuntime

Исходный commit: bef1c22e545d7d68af6acc99c0284ebc78a707c8.
Версия: JavaRuntime 5.0.9 для GravitLauncher 5.7.13.

Исходники Java, FXML, CSS, изображения и шрифты включены в FlameLauncher
как обычные файлы. Изменения коммитятся в ветку feat/flame-gui этого
репозитория. Подмодуля GUI, автоматической синхронизации с upstream и
загрузки исходников интерфейса из чужого репозитория при сборке нет.

Сохранены исходная лицензия MIT (LICENSE) и лицензия шрифта
(runtime/styles/FONT OFL.txt). При распространении сохраняйте эти файлы.

Настройки API, обновлений и внешних зеркал относятся к ядру лаунчера;
перенос GUI сам по себе не меняет их и не исправляет уязвимости из аудита.
